Как включить / выключить
========================

Папка надстройки рядом с AutoCell:
  C:\AutoCell
  C:\AutoCell_addon

Включить, не трогая работающий склад
  1. ПКМ install_addon.bat → от имени администратора
  2. Служба не останавливается и не запускается.
  3. Надстройка начнёт работать после штатного ребута ПК
     (или когда служба сама перезапустится).
  4. После ребута в браузере справа внизу: «надстройка ON»

Если AutoCellBackend уже STOPPED
  Не запускайте install повторно в надежде поднять службу.
  1. ПКМ emergency_start.bat → от имени администратора
     Возвращает main.py / app.py и запускает лежащие службы.
     Уже работающую службу не останавливает.
  2. Когда склад снова на штатном коде, ещё раз install_addon.bat.
     Это только пропишет надстройку на следующий ребут.

Выключить
  1. ПКМ remove_addon.bat → от имени администратора
  2. Тоже без стопа и без старта. Оригинал — со следующего старта службы.


Подводные камни
---------------
1. AutoCell\setup.bat заново создаёт службы на original main.py/app.py.
   После setup.bat надстройку нужно включить снова.

2. Не запускайте setup.bat / uninstall_services.bat «чтобы починить
   надстройку» — это сносит службы AutoCell.

3. Повторный install не затирает nssm_backup.json путями надстройки.
   Снимать только remove_addon.bat или emergency_start.bat.

4. Если nssm get вернул битый путь, install ничего не пишет и выходит.
   Проверка: nssm get AutoCellBackend Application

5. TYPE 1/5 блокируется только если кран waiting и empty=0.
   Идущий цикл и ошибка чтения ПЛК/БД тип не меняют.

6. Индексы waiting: ASRS1=20, ASRS2=46 в кортеже data_read_asrs_actions.
   Если plc_maping.py поменяют порядок полей — поправьте
   config.json → entry_block.waiting_index.

7. Ячейки 1–93 / 94–186 зашиты в config. Смена раскладки склада —
   правьте asrs1_cells / asrs2_cells.

8. После включения не двигайте AutoCell_addon: NSSM держит полный путь
   к core\run_backend.py и run_frontend.py.

9. Нужны уже установленные службы AutoCellBackend / AutoCellFrontend
   (сначала AutoCell\setup.bat).

10. Значок «надстройка ON» = фронт запущен через обёртку.
    Сам backend смотрите в AutoCell\logs\backend.log и state\addon.log.
